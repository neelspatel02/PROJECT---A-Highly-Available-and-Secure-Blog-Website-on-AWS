My AWS Blog

This is my blog website hosted on S3 bucket, mentioning the AWS services that i use to host it !!.

AWS S3

Amazon S3 is a scalable object storage service that allows you to store and retrieve any amount of data.

Amazon Route 53

Amazon Route 53 is a scalable and highly available domain name system (DNS) web service.

Amazon CloudFront

Amazon CloudFront is a content delivery network (CDN) that securely delivers data, videos, applications, and APIs.

AWS Certificate Manager

AWS Certificate Manager provides a simple way to manage and deploy SSL/TLS certificates for use with AWS services.
